# Аналитика интернет-магазина

Учебный проект: база данных SQLite, SQL-запросы, анализ данных с Pandas и графики Matplotlib.

## Файлы
- `setup_db.py` — создаёт базу `shop.db` и таблицу `sales`, добавляет 21 запись (повторный запуск дубликатов не создаёт).
- `check_db.py` — SQL-запросы к базе (день 1).
- `analysis.py` — загрузка данных из SQLite, расчёт показателей и построение графиков (день 2).
- `shop.db` — база данных.
- `charts/` — графики в формате PNG.

## Таблица `sales`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Уникальный идентификатор |
| product | TEXT | Название товара |
| category | TEXT | Категория (Техника, Аксессуары, Канцелярия, Мебель) |
| price | INTEGER | Цена, тенге |
| quantity | INTEGER | Количество проданных единиц |
| sale_date | TEXT | Дата продажи (ГГГГ-ММ-ДД) |

## Запуск
```
python -m pip install pandas matplotlib
python setup_db.py
python check_db.py
python analysis.py
```
Программа `analysis.py` каждый раз читает данные из `shop.db` и заново считает показатели и перестраивает графики. Чтобы дополнительно открыть графики на экране: `set SHOW_CHARTS=1` (Windows cmd) или `$env:SHOW_CHARTS=1` (PowerShell) перед запуском.

## Графики
- `charts/revenue_by_product.png` — выручка по товарам (столбчатая диаграмма);
- `charts/revenue_by_category.png` — доли категорий в выручке (круговая диаграмма);
- `charts/quantity_by_product.png` — количество проданных единиц по товарам (столбчатая диаграмма).

## Выводы
1. Категория «Техника» приносит 74,2% всей выручки, хотя по числу позиций она не больше других категорий.
2. Три самых прибыльных товара (Смартфон, Ноутбук, Планшет) дают 54,5% общей выручки.
3. Больше всего единиц продано по товару «Ручка» (50 шт.), но в выручке она на последнем месте: дешёвые товары продаются массово, а основную выручку дают дорогие.
