# Аналитика интернет-магазина — День 1

Учебный проект: создание базы данных SQLite и работа с SQL-запросами.

## Файлы
- `setup_db.py` — создаёт базу `shop.db`, таблицу `sales` и добавляет 21 запись (повторный запуск дубликатов не создаёт).
- `check_db.py` — выводит данные и выполняет SQL-запросы из заданий.
- `shop.db` — готовая база данных.

## Таблица `sales`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Уникальный идентификатор |
| product | TEXT | Название товара |
| category | TEXT | Категория |
| price | INTEGER | Цена (тенге) |
| quantity | INTEGER | Количество проданных единиц |
| sale_date | TEXT | Дата продажи (ГГГГ-ММ-ДД) |

Категории: Техника, Аксессуары, Канцелярия, Мебель.

## Запуск
```
python setup_db.py
python check_db.py
```

## SQL-запросы в `check_db.py`
- товары дороже 20 000 тенге (`WHERE`);
- товары категории «Техника» (`WHERE`);
- сортировка по цене по убыванию (`ORDER BY`);
- количество записей (`COUNT`);
- количество записей по категориям (`GROUP BY`).
